# Usage log

Moments when Agentarium's view was wrong, late or useless during real use. This log decides which `needs-triage` issues in `issues/` get promoted (06 late SessionStart, 07 MCP tools as `think`, 08 stale backpressured client).

One bullet per moment: date, what you saw, what was true, and how much it hurt triage (none / annoying / missed something). When an entry is triaged, append `→ issue NN` or `→ dismissed: <reason>`.
