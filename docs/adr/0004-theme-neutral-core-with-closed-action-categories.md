# Theme-neutral core with a closed set of action categories

The core, schema and adapters never use theme words. Themes can only express the Action categories the core emits, so the set is a public contract: adding one later breaks existing themes. It stays closed for v1 and is frozen only after real Claude Code payloads show the nine categories cover real tool calls. Extension by themes is reconsidered when community themes become real.

## Amendment, 2026-10-10: frozen

The nine categories are frozen for v1, before any Theme art exists. Evidence: real Claude Code payloads map onto the nine (`docs/research/hook-payloads.md`), MCP tools map by verb rather than to `think` (daily-use 07), and the Codex gap review kept the set unchanged (`docs/research/codex-gap-decisions.md`). Adding a category now means new art and a new Station in every Theme.
